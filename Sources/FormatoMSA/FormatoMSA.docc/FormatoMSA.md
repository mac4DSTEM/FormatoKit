# ``FormatoMSA``

Reads and writes the EMSA/MAS spectral data format (`.msa` and `.ems`). The module has no public API yet: its format is not registered.

## Overview

The module is empty until its format is registered and its readers are written. The article <doc:Scope> says what it will read.
